# Architectural Assumptions Register

Distinct from `docs/adr/` — an ADR records a decision already made; this records things we currently *believe* and are building on. If evidence later rejects one, that's an explicit trigger for a new ADR, not a silent pivot. Status: Active (believed true, acted on) / Validated (confirmed by experiment) / Rejected (disproven — see linked ADR).
