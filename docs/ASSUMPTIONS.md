# Architectural Assumptions Register

Distinct from `docs/adr/` — an ADR records a decision already made; this records things we currently *believe* and are building on. If evidence later rejects one, that's an explicit trigger for a new ADR, not a silent pivot. Status: Active (believed true, acted on) / Validated (confirmed by experiment) / Rejected (disproven — see linked ADR).

| A-004 | The 2015 persistence-RMSE anomaly (0.898 vs. 0.50-0.63 in other years) does not represent a fundamental regime break that would invalidate 2002-2014 patterns for the Sep 2015-Dec 2018 test period — a period whose very first month (September 2015) immediately follows the last month of training data (August 2015) | Medium-High | **Resolved by Experiment 2** (`notebooks/02_forecastability.ipynb` §7-8): partial-year/seasonal-composition artifact explicitly ruled out (pooled 2002-2014 Jan-Aug vs Sep-Dec persistence RMSE ratio only 1.03). Verdict: genuine regime characteristic, not an artifact — but this also means 2002-2014 volatility levels should NOT be assumed representative of the Sep 2015-Dec 2018 test period, since it immediately follows this anomalous window. | Validated (the "does not invalidate 2002-2014 patterns" framing) with an important caveat now explicit: the *original* statement undersold the risk — 2015 isn't dismissible, so downstream validation/feature design must plan for comparably volatile stretches, not just treat the anomaly as noise to move past | Project Phase 1, Experiment 2 (complete) |
